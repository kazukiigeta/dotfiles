# Dotfiles

Personal dotfiles managed with [chezmoi](https://www.chezmoi.io/).

---

## 🚀 Quick Start

Install chezmoi (see [official instructions](https://www.chezmoi.io/install/)):

```bash
cd ~/.local
sh -c "$(curl -fsLS get.chezmoi.io)" -- init --apply https://github.com/kazukiigeta/dotfiles.git
```
